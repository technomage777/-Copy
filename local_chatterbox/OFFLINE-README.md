# Story Voice Studio — Offline Chatterbox

Drop these files into your existing local_chatterbox folder:

- offline_voice_studio.html
- server.py
- Start Chatterbox Local.command

No reinstall is required if Chatterbox already runs locally.

After replacing the files, double-click Start Chatterbox Local.command.
The local interface opens at:

http://127.0.0.1:8765

Once the Python packages and Chatterbox model have already been downloaded to this Mac, generation and the interface work without internet access.

The reference voice and settings are saved locally in the browser on that Mac.
